What the numbers mean

Both shallow and filtered sparse Git are real baselines. The archive baseline uses Git directly on the server filesystem and avoids transport entirely. The gateway is useful when callers need a language-neutral read API or reusable verified object cache. Git remains preferable for editing, history traversal and ordinary development.
